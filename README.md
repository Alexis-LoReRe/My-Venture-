# My Venture

An AI-powered web application built over a 7-week roadmap, from builder setup through a final demo.

## Roadmap

| Week | Focus |
|------|-------|
| 0 | Builder Setup |
| 1 | Generative Core |
| 2 | Research Agent |
| 3 | Product Architecture |
| 4 | Marketing Engine |
| 5 | Dashboard |
| 6 | Final Demo |

## Tech Stack

- **Framework:** Next.js 16 (App Router)
- **Language:** TypeScript
- **Styling:** Tailwind CSS v4
- **Runtime:** React 19

## Running Locally

**Prerequisites:** Node.js 18+

```bash
# Install dependencies
npm install

# Start the development server
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

## Other Commands

```bash
npm run build   # Production build
npm run start   # Start production server
npm run lint    # Run ESLint
```
